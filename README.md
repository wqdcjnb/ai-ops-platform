# AI 运营平台

面向电商运营团队的 AI 接入与用量管理方案。项目计划通过统一网关为每位成员发放独立 API Key，并按人员、用途和模型管理权限、额度与调用记录。

## 当前阶段

仓库目前处于原型开发与基础真实化阶段。需求、架构、安全规则、UI 方案与验收标准已经建立；运营控制台已具备“统一入口”本机只读版、“运营总览”演示数据版，以及人员、人员详情、Key 管理、额度与限流、用途与路由、模型与渠道、上游账号、用量与日志、告警中心、审计日志、对话审计和系统设置页面；员工端已具备独立的本人自助演示页。BFF 已能探测基础服务，并已接入 SQLite、密码摘要登录、仅保存哈希的持久化会话、HttpOnly + SameSite=Strict Cookie、CSRF 校验、自动清理过期/超期撤销会话、服务端 RBAC 和部门负责人本部门数据范围；人员、Key、月度软目标、调用元数据、告警事件/规则、审计事件及合成对话审计元数据已读取平台数据库。模型与渠道支持默认模拟模式和管理员主动切换的 New API 只读配置目录；当前真实目录为空，非空字段映射通过模拟接口验证。真实用量、健康指标、计费与完整生产权限仍待验收。文档中标注为“待验证”或“计划开发”的能力不代表已经实现。

已确认的方向：

- 客户端：Codex Desktop、WorkBuddy
- 统一管理：New API
- 正式上游：官方 API
- 实验上游：CLIProxyAPI（CPA），只用于隔离测试
- 本机测试数据库：SQLite
- 管理界面：Vue 3、TypeScript、Vite、Tabler、Pinia、ECharts
- 首批试点：5–10 名运营人员

```text
Codex Desktop / WorkBuddy
          │ 每人独立 API Key
          ▼
       New API
   ┌──────┴────────┐
   ▼               ▼
官方 API 渠道    CPA 实验渠道
正式业务          Pro OAuth 隔离测试
```

Key 轮换现已完成本地 SQLite 模拟闭环：管理员确认后会原子创建继承原人员、用途和模型的新 Key，并停用旧 Key；完整新 Key 只在首次成功响应中展示，重试不会再次返回。轮换请求要求 CSRF、原因确认和幂等操作编号，审计仅保存掩码及状态变化摘要，不保存完整 Key 或原因原文；不会调用 New API 或修改真实凭据。除本地演示人员和 Key 的创建/停用/轮换外，其余高风险管理写操作仍保持关闭。

本地演示人员停用现已开放：管理员确认后，人员状态和其仍有效 Key 会在同一 SQLite 事务中停用；该人员后续本地登录及已有会话访问会因用户状态校验被拒绝。请求要求 CSRF、原因确认和幂等操作编号，审计只记录状态与回收数量，不保存原因原文；不会调用 New API 或修改真实账户。新生成 Key 的人员头像则统一使用姓名后两个字，例如“陈安琪”显示为“安琪”。

本地月度软目标调整现已开放：管理员可在额度树中选择公司、部门、人员、用途或 Key 范围，查看调整后的预计使用率后确认写入 SQLite。请求要求 CSRF、原因确认和幂等操作编号，月度策略与不含原因原文的审计摘要同一事务提交；目标在 BFF 重启后仍会保留。该功能始终是软提示，不会调用 New API、修改真实预算或开启硬额度拦截。

本地并发预留演练现已开放：管理员可在额度详情创建预留，并在模拟请求完成后执行结算，或在失败路径执行取消释放。状态、幂等编号和安全审计摘要写入 SQLite，页面明确标记为演练；它不参与硬额度判定、不阻断请求、不调用 New API，也不代表真实网关并发账本。

员工临时额度申请现已进入本地审批轨道：员工可提交点数、时长和说明，管理员或部门负责人在额度页批准/拒绝；该流程只更新 SQLite 软目标和审计摘要，不会开启硬额度。

本地路由降级策略调整现已开放：管理员可在用途与路由详情中调整 SQLite 模拟策略的超时、429、5xx 处理方式和最大重试次数。请求要求 CSRF、原因确认和幂等操作编号，策略覆盖项与不含原因原文的审计摘要同一事务提交；重启后仍会保留。没有同组备用渠道时不能选择切换备用，客户端选渠道和正式/实验跨组回退始终由服务端禁止。该功能不会调用 New API、修改真实路由或影响请求流量。

本地模拟渠道复检现已开放：管理员可在模型与渠道页的模拟渠道详情中确认更新 SQLite 健康快照。请求要求 CSRF、原因确认和幂等操作编号，快照与不含原因原文的审计摘要同一事务提交；重启后仍会保留。它不发起真实探测、不调用 New API、不使用管理凭据，也不会修改模型、渠道、路由或流量；New API 数据模式继续只读。

告警中心当前从 SQLite 读取 8 条可重复模拟事件与 8 条只读规则；事件详情只保留脱敏摘要和关联请求 ID。超级管理员或管理员可确认、关闭本地模拟告警，状态与不含处置说明原文的审计摘要会同一事务保存，并可按返回的精确审计事件 ID 跳至该处置记录；审计详情也可按受限告警 ID 返回对应事件。它不会发送通知、调用 New API 或改变真实事件。规则编辑、静默、真实告警采集和通知将在后续独立验收。

对话审计继续使用不含真实正文的合成数据。SQLite `conversation_audit_records` 仅持久化 7 条合成记录的人员、掩码 Key、用途、模型、策略、脱敏/归组/计量和到期元数据；查看合成轮次时，SQLite 另行持久化操作者显示名、目标、请求 ID、时间、是否已填写原因及原因长度，并仅向超级管理员显示最近 20 条查看元数据。SQLite `conversation_usage_links` 还为这 7 条合成记录明确保存对应的模拟用量请求 ID；页面会将审计请求 ID 与模拟用量请求 ID 分开显示，并可跳转到该模拟用量记录的筛选结果。仅超级管理员的模拟用量详情可返回该映射并跳回已选中的审计记录；其他角色不会收到审计记录编号或链接。该映射不代表真实网关请求 ID 透传或真实调用日志对账。BFF 启动时会将到期的合成元数据设为不可访问，并记录“SQLite 从未存储正文”的本地证明；它不是实际正文删除证明。原因原文、认证信息、完整 Key、原始提示词、工具参数/输出和真实对话正文均不保存。独立采集、加密、真实访问审计、真实正文清理和高风险内容操作仍未接入。

系统设置中的业务口径和五项高风险功能开关已从 SQLite 读取可重复的模拟配置，并在页面标记为 SQLite 来源；它们仍为只读，未开放设置编辑、凭据写入、连接验证、备份下载或恢复演练。组织、留存与备份状态继续明确标记为演示或未验证数据。

系统设置中的公司、部门、人员与五类角色目录也已由 SQLite 模拟组织聚合展示；真实组织同步、角色授权与高权限变更审计仍待单独验收。

调用元数据、对话审计正文、操作审计和导出文件的留存期限也已由 SQLite 模拟策略读取；除合成对话元数据的启动时到期标记与无正文证明外，这不包含任何自动清理或删除能力，真实清理任务、删除证明与恢复流程均未启用。

系统设置的备份状态已由 SQLite 安全元数据读取，并在数据库约束中固定为“未配置、无备份记录、禁止浏览器下载”；不会创建备份文件或执行恢复操作。

本地认证安全审计已追加记录登录成功/失败、退出、未认证访问、角色拒绝和 CSRF 拒绝，并与 BFF 请求 ID 关联。审计摘要不保存密码、用户名输入、Cookie、会话/CSRF 值、查询参数、请求正文、来源 IP 或客户端指纹；每次读取都会重算 SQLite SHA-256 事件链，并用“事件数 + 链头摘要”检查点检测尾部删除，不一致时拒绝新增审计事件。该本地校验无法抵御同时拥有数据库写权限的攻击；受限数据库权限、外部完整性锚点、来源采集、全量高风险写操作覆盖和跨服务审计仍待生产验收。

员工自助页的本人资料、掩码 Key 和用量现按已认证员工 ID 从 SQLite 模拟数据读取；模型别名目录仍明确标为 DEMO。该范围不返回其他人员、完整 Key、供应商、实际模型、上游渠道或管理配置，也不代表已经完成与真实网关账本的对接。

运营总览的五项指标、7/30 天趋势、人员排行、渠道摘要和告警摘要现从 SQLite 模拟调用、额度与告警记录聚合，并在页面标记为“SQLite 模拟数据”。这些汇总不是实时网关健康检查、真实日志或供应商账单；完整 Key、实际模型、认证信息、成本金额和上游完整错误正文不会返回浏览器。

统一入口的待处理事项和“人员与 Key”入口摘要也从 SQLite 模拟告警和掩码 Key 聚合，可直接进入告警中心或 Key 管理；其数量与到期风险仅用于本地演示，不代表真实网关事件或正式凭据状态。

统一入口的“上游账号”和“待处理事项”卡片现已连接到上游账号页和告警中心；前者显示实时连接探测，后者仍展示 SQLite 模拟告警与掩码 Key 摘要。

上游账号详情在当前模拟账号出现余额、认证或连接异常时，可按受限的关联对象 ID 进入告警中心并精确筛选相关 SQLite 模拟事件；页面会提示关联筛选状态并允许清除。该跳转不传递凭据、上游响应正文或真实账号数据。

告警详情中的关联请求 ID 现可直接进入用量与日志页，并标明“来自告警事件的模拟调用关联”；用量页仅按该请求 ID 筛选 SQLite 模拟元数据，不代表真实网关或上游请求链路。对话审计进入用量页时仍保留独立来源说明。

运营总览的告警、人员与部门、模型与渠道入口已连接到对应页面；管理员可从总览进入 Key 管理创建本地演示 Key，告警行会携带关键词打开告警中心筛选，所有入口均遵循当前角色权限和 SQLite 模拟数据边界。

## 安全边界

本仓库是公开仓库，不得提交以下内容：

- 官方 API Key、个人 Bearer Key、CPA 管理密钥
- OAuth Token、认证文件、浏览器登录信息
- 数据库文件、备份、运行日志和客户业务数据
- 包含密码或密钥的 `.env`、Compose 覆盖配置和截图

员工只接触 New API 地址及个人 Key。CPA、官方 API Key和 OAuth 凭据由管理员单独保管。
