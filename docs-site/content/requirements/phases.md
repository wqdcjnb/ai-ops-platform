# 实施范围

## 当前交付：文档中心

统一 Markdown、分类导航、中文搜索、原文下载、后台入口与决策记录。使用本机地址，无业务管理 API 接入。

## 一期：团队试点

1. 验证两种客户端到网关及 CPA 的完整链路。
2. 独立员工账号、Key、模型权限、额度和撤销。
3. 配置业务模型别名，验证上游账号调度、流式输出与失败行为。
4. 建立部门/岗位字段和最小预算规则。
5. 提供人员用量看板和基本异常事件记录。
6. 完成凭据隔离、日志脱敏、安全与任务连续性验证。

一期以小范围试点通过为准，尚未承诺具体人数或交付日期。

## 二期：精细运营

临时额度申请与审批、企业微信/钉钉通知、月报、提示词模板、敏感信息自动识别、模型质量评估、账单核对、企业单点登录、多机高可用。

## 待决定

预算单位、周期重置时区、试点人员与上游账号、消息通知渠道、真实成本核算口径。在这些问题确定前，多层预算按需求记录，不作为已实现能力。
