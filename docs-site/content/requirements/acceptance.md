## 业务平台验收（待执行）

- 两位员工分别调用，日志与费用能够正确归属，不能访问对方数据。
- 未授权模型在网关拒绝；撤销 Key 后 60 秒内失效。
- 预算耗尽、并发超限、取消和失败请求具有可核对的处理结果。
- Codex Desktop 和 WorkBuddy 分别完成流式输出、工具调用和长任务验证。
- 客户端重启、Provider 切换、账号故障切换后，记录与任务恢复结果明确。
- 网关不能泄漏上游凭据，普通用户不能访问管理接口。
- 测试敏感标记不出现在正常日志、导出与监控中。
- 看板估算用量与请求记录一致，上游实际账单单独核对。
- 未开启对话审计的 Key 只生成用量元数据，不保存请求或响应正文。
- 开启审计的测试 Key 能以同一请求 ID 关联用户输入、模型输出、工具调用摘要和 New API 用量记录。
- Responses 链式请求只能在存在会话标识或 `previous_response_id` 时归组；无法可靠归组时必须显示为独立调用。
- 对话页面只向超级管理员开放，普通管理员和员工均不能读取其他人的内容。
- 对话内容中的测试密钥、手机号、地址和订单信息按策略脱敏；Authorization、Cookie 和 OAuth Token 的保存结果为零。
- 查看、搜索、导出与删除对话均产生访问审计，留存到期后正文可验证删除。

通过聊天测试不代表工具执行、MCP、图片或长期稳定性已通过。
