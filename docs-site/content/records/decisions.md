## 事实源边界

- CPA：Codex OAuth、认证账号、模型目录、上游额度和账号状态。
- New API：人员用户、员工 Token/API Key、单模型限制、额度/有效期字段、渠道、请求日志和 Token 状态。
- AI OPS：人员与 Token 的展示映射、同步状态、管理审计和加密正文审计索引；不生成第二套可调用 Key，不伪造额度。

## 仍待技术确认

1. 当前 New API 版本中“永不过期”和“无限额度”的实际字段/枚举值，以及停用、删除、重新生成接口的具体合约。
2. New API 请求处理链路中采集真实 Prompt、工具调用和流式回复的改造位置。
3. CPA 额度适配器对当前版本和后续版本的字段兼容策略。

历史资料中关于官方 API、多个 Provider、员工自助、部门预算、用途路由和独立网关的内容均不属于当前产品范围，除非后续重新决策。
