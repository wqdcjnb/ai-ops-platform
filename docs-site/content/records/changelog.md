## 2026-09-17 · 统一入口 SQLite 任务汇总

- 统一入口的待处理事项与“人员与 Key”入口摘要改为从 SQLite 的模拟告警和掩码 Key 聚合；待办可直接跳转至告警中心或 Key 管理。

- 服务矩阵仍是本机实时探测，首次配置清单保持只读配置提示；真实告警/Key/部署采集、处置写操作与数据范围继续未接入。

## 2026-09-17 · 运营总览 SQLite 聚合

- 指标、渠道成功率与延迟均是可重复的模拟元数据聚合，不代表实时网关健康、真实调用日志或供应商账单；未设置个人额度目标时明确显示“未配置”。
- 聚合响应不返回完整 Key、实际模型、成本金额、认证信息或上游完整错误正文；写操作和告警处置入口继续关闭。
