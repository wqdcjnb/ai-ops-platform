# 客户端接入验证

当前未通过本站修改 Codex Desktop 或 WorkBuddy 配置，也未完成端到端推理测试。

## 接入前准备

确认客户端版本，备份客户端配置与任务数据；在网关签发低额度测试用户令牌，并确定可用模型。令牌不写入本文档或截图。

## 验证顺序

1. 按当前客户端支持方式设置网关地址、测试令牌与模型。
2. 分别记录实际使用接口，确认网关与 CPA 支持完整请求链路。
3. 完成普通问答、流式回答、工具调用和结果回传。
4. 测试取消、长任务、网关故障、账号切换和客户端重启。
5. 验证历史记录仍可访问；更换客户端不会自动迁移原任务。
6. 撤销测试令牌，确认不能继续发起新请求。

## 结果记录模板

```text
日期：
客户端及版本：
New API / CPA 版本：
测试模型与接口（不含密钥）：
测试场景：
结果：通过 / 失败 / 不适用
证据与问题：
```

最终接入指南以通过以上步骤后的实际配置为准。
