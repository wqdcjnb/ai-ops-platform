# 常用入口

::: info 统一入口
AI OPS 是本项目唯一的管理入口。New API 和 CPA 随 Docker Compose 一起运行，是由 AI OPS 服务端调用的内部依赖；它们的管理网站不属于日常工作流，本页不提供对应入口。
:::

| 服务 | 角色 | 管理方式 | 入口 |
| --- | --- | --- | --- |
| AI OPS | 唯一管理后台 | 超级管理员使用 | [打开 AI OPS](http://127.0.0.1:4174/) |
| New API | 员工 Token、渠道、请求日志服务 | AI OPS 服务端适配器自动调用 | 不提供独立管理入口 |
| CPA | Codex OAuth、账号、模型和额度服务 | AI OPS 服务端适配器自动调用 | 不提供独立管理入口 |

## 使用说明

1. 在项目根目录用 Docker Compose 启动整套服务；AI OPS 会等待 New API 和 CPA 健康检查并显示依赖状态。
2. 管理员只登录 AI OPS，在统一页面完成人员导入、CPA OAuth、模型选择、New API 渠道同步、员工 Key 管理和按 Key 审计。
3. CPA 管理页面和 New API 管理页面不需要打开；不要把管理令牌、CPA 客户端 Key 或 OAuth 文件复制到浏览器。
4. 如果依赖不可用，查看 AI OPS 的连接、认证、同步和恢复提示；不要用演示数据代替真实状态。
5. Codex OAuth 需要官方授权跳转时，由 AI OPS 发起并在授权完成后回到 AI OPS；这不等同于进入 CPA 管理后台。

## 当前运行地址

地址以根目录 Compose 配置和 AI OPS 页面显示为准。New API/CPA 的本机端口仅用于受控调试或健康检查，不是管理员操作入口，也不代表已完成认证或渠道同步。
